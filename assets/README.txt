assets/
=====

Place your project images here, for example:

  screenshot-desktop.png   → the game screen on a desktop (Setup + Game view)
  screenshot-mobile.png    → the responsive mobile layout
  screenshot-terminal.png  → ./hangman running in the terminal (ASCII hangman)
  hangman-wasm.png         → the header badge showing "C++ / WebAssembly"
  favicon.png              → optional site icon

The game itself needs no external images: the hangman is drawn with inline SVG
and all icons are emoji / CSS, which keeps the project light and offline-friendly.
