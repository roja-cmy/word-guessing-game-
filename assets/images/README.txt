assets/images/  —  artwork & screenshots
=======================================

WORD HUNT needs no image files to run:

  * the adventure background (sun, clouds, hills, trees, birds) is drawn with CSS,
  * the explorer character and the jungle branch are inline SVG,
  * all icons are emoji, so the game works offline and loads instantly.

Put your own artwork and documentation screenshots here, for example:

  01-home.png          – the home screen with the WORD HUNT logo and PLAY button
  02-category.png      – the 7 category cards
  03-difficulty.png    – Easy / Medium / Hard cards
  04-game.png          – the game screen (explorer, word tiles, keyboard)
  05-win.png           – the victory screen with confetti
  06-gameover.png      – the game-over screen
  07-mobile.png        – the responsive mobile layout
  08-terminal.png      – ./wordhunt running in the terminal
  09-architecture.png  – the C++ <-> browser diagram from the README
  favicon.png          – optional 64x64 site icon

Add them to the README with normal Markdown image syntax:
  ![Home screen](assets/images/01-home.png)
